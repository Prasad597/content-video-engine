EXPERIMENT 001 V2 — RECORDING SCRIPT / 39 SECONDS

Delivery: warm, experienced Indian teacher; conversational Indian English with
natural Telugu code switching. Curious opening, brief thinking pause, confident
answer; slow down for “does NOT” and the final rule. No newsreader delivery,
shouting, cinematic delivery or exaggerated “boom”.

Telugu is romanized here for the speaker. Pronounce it naturally as Telugu,
not as English spelling. Keep Java class names and technical terms in English.
Times and bracketed cues are direction, NOT spoken text. Aim for the windows;
record naturally first, then align caption/beat timestamps to the recording.

00.0–03.5 [curious; let the viewer choose; brief pause after the question]
“Will this code compile? … Mee answer?”

03.5–07.0 [confident reveal; slight stress on “runtime”]
“Yes! But b zero ayithe, runtime lo ArithmeticException.”

07.0–10.5 [ask like a teacher; small pause before the answer]
“Mari handle cheyyamani enduku force cheyyaledu? … Unchecked exception.”

10.5–17.0 [slower and clear; stress NOT, catch, declare]
“The compiler does NOT require you to catch it,
or declare it with throws.”

17.0–24.0 [guide the execution, don't rush the class name]
“Oka run chuddam. getValue zero return chesindi anukondi.
Ippudu ten divided by zero … ArithmeticException.”

24.0–28.0 [trace the hierarchy; stress RuntimeException]
“Ee hierarchy lo, RuntimeException ni chudandi.”

28.0–32.0 [examples appear; let the screen name them]
“Ee examples anni daani subclasses. Anduke unchecked.”

32.0–39.0 [slow, assured interview rule; finish with a short hold]
“Interview lo idi gurthupettukondi:
RuntimeException and its subclasses are unchecked.
No mandatory catch or throws.”

OUTPUT / HANDOFF
- Export the spoken take as public/audio/narration-v2.mp3, starting at time zero.
- Deliver one clean 39-second take, including the planned pauses. No music/SFX
  baked into it. Use a clean, unclipped recording; narration volume defaults to 1.
- Listen to Telugu pronunciation and class names before using any external TTS.
- The visual's getValue() is a defined method returning an int. This run returns 0;
  it is NOT an undefined method or a compile-time constant division example.
- Captions are selective phrase cues, not a full accessibility transcript. Main
  English technical text on screen carries the rest. Sync after the final take.
- No TTS vendor, credentials, generated voice or enhancement is part of this repo.
