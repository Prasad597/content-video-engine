[HOOK]

Two Java lists run almost the same loop.

We modify both during iteration.

ArrayList crashes.

CopyOnWriteArrayList doesn't.

Why?

[FAIL_FAST]

With ArrayList, the iterator is fail-fast.

If the list is structurally modified unexpectedly during iteration...

it can throw ConcurrentModificationException.

[SECOND]

CopyOnWriteArrayList behaves differently.

Its iterator can continue without that exception.

[WHY]

The iterator works on a snapshot of the array created when iteration started.

Later writes create a new copy.

They don't change the snapshot being iterated.

[TRADEOFF]

But that doesn't make CopyOnWriteArrayList always better.

Copying on every write has a cost.

[RULE]

So remember:

Fail-fast detects unexpected structural modification.

Snapshot iteration avoids that conflict...

but you pay for the copies.
